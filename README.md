## 👨‍💻 About

I'm a self-taught developer and security researcher working across **Android, security, automation, backend systems and independent software products**.

Most of my work starts with curiosity — figuring out how something works, how it can be improved, or whether an idea is worth building — and usually ends with a real project.

I enjoy working on things that involve:

- 📱 Native Android apps and games
- 🔐 Security research and tooling
- ⚙️ Automation and developer utilities
- 🌐 Backend and web infrastructure
- 🧪 Technical prototypes and experiments
- 🚀 Taking projects from idea to release
